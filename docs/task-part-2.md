Приложение нужно обернуть в контейнерный компонент (Container), который будет содержать общий для всего приложения стейт:
— товары в корзине (Map или объект: id товара → количество)
— текущая страница (витрина TV / витрина Phone / витрина Laptop / корзина)

Контейнер передаёт текущее состояние и сеттеры пропсами в Header и в область контента. Смотрите описание структуры в разделе Компоненты ниже.

ВНИМАНИЕ: это ВРЕМЕННОЕ решение. В будущем мы заменим его на нормальный роутер и глобальный стейт-менеджер, но пока делаем так, т.к. нам нужно научиться делиться состоянием через пропсы. Опционально можете попробовать реализовать глобальный стейт через React Context или sessionStorage — см. раздел «Опциональный глобальный стейт».
Сторонними библиотеками пользоваться НЕЛЬЗЯ.

Container (новый корневой компонент)
Содержит общий стейт приложения и рендерит структуру:

<Container>
  <Header />
  <Content />
  <Footer />
</Container>

В Container хранятся:
— pageType: текущая страница ('tv' | 'phone' | 'laptop' | 'cart'). По умолчанию 'tv'.
— cart: объект или Map, где ключ — id товара, значение — количество в корзине.

Container передаёт pageType, cart и соответствующие сеттеры пропсами в Header и Content.

Content (новый компонент)
Рендерит нужную страницу в зависимости от pageType (интерфейс компонентов страницы примерный, вы можете указать свой):

const Content = ({ pageType, setPageType, cart, setCart }) => {
  return (
    <>
      {pageType === 'tv' && <TvListing cart={cart} setCart={setCart} pageType={pageType} setPageType={setPageType} />}
      {pageType === 'phone' && <PhoneListing cart={cart} setCart={setCart} pageType={pageType} setPageType={setPageType} />}
      {pageType === 'laptop' && <LaptopListing cart={cart} setCart={setCart} pageType={pageType} setPageType={setPageType} />}
      {pageType === 'cart' && <Cart cart={cart} setCart={setCart} pageType={pageType} setPageType={setPageType} />}
    </>
  );
};

Home → TvListing
Переименуйте компонент Home в TvListing. Теперь он отвечает только за витрину телевизоров.

PhoneListing, LaptopListing
Аналогичны TvListing, но фильтруют товары по category === 'phone' и category === 'laptop' соответственно. Структура идентична TvListing.

Cart (страница корзины)
Как попасть: при клике на иконку корзины в Header, pageType меняется на 'cart'.
Если корзина пуста — показывается сообщение «Your cart is empty» и кнопка «Continue Shopping» (возвращает на pageType === 'tv').

Список товаров:
Каждый товар в корзине отображается строкой: миниатюра, бренд, модель, кнопки управления количеством, цена за позицию.
— Кнопка «+» (plus): увеличивает количество данного товара на 1
— Кнопка «−» (minus): уменьшает количество данного товара на 1. Если текущее количество = 1, товар удаляется из корзины полностью
— Кнопка удаления (trash icon): удаляет товар из корзины полностью, независимо от количества
— Цена за позицию: product.price × количество. Формат $X,XXX (без центов)

Сводка заказа (Order Summary):
— Subtotal: сумма (product.price × количество) по всем товарам в корзине
— Tax (8%): Subtotal × 0.08. Округление до двух знаков после запятой (например: 159.92)
— Shipping: текст «Calculated at checkout»
— Total: Subtotal + Tax. Округление до двух знаков после запятой
Все денежные значения в сводке отображаются с двумя знаками после запятой (например $1,299.00, $159.92).

Кнопки:
— "Proceed to Checkout" — при нажатии пока ничего не делаем
— "Back to Shopping" — возвращает на pageType === 'tv'

ВАЖНО: при смене раздела (tv → phone → laptop) состав корзины НЕ меняется! Корзина — глобальное состояние.

Header
— Логотип «TechStore» (кликабельный — переключает на pageType === 'tv')
— Навигация: три кнопки-таба — TV, Phone, Laptop. При клике меняют pageType.
— Иконка корзины с бейджем (количество товаров). При клике — pageType === 'cart'.
— Иконка пользователя (пока без функционала).

Footer — без изменений из итерации 1.

Вместо (или вместе с) передачей пропсов через Container, попробуйте реализовать глобальный стейт одним из способов:

1) React Context
— Создайте Context для корзины и текущей страницы.
— Оберните приложение в Provider.
— Используйте useContext в компонентах, которым нужен доступ к глобальному стейту.
— Сторонние библиотеки использовать НЕЛЬЗЯ — только встроенный React.createContext / useContext.

2) sessionStorage
— sessionStorage — встроенный в браузер API (window.sessionStorage). Позволяет хранить данные в формате ключ-значение, которые сохраняются на время текущей вкладки.
— Основные методы: sessionStorage.setItem(key, value) — записать, sessionStorage.getItem(key) — прочитать, sessionStorage.removeItem(key) — удалить. Значения хранятся как строки, поэтому объекты нужно сериализовать через JSON.stringify / JSON.parse.
— Если занести корзину в sessionStorage, она переживёт перезагрузку страницы (в рамках одной вкладки).
— Для удобства вынесите все обращения к sessionStorage в адаптер (отдельный файл) в уровне /data, например: src/data/cartStorage.js с функциями saveCart(cart) / loadCart().

Можно использовать оба подхода одновременно: Context для доступа из компонентов + sessionStorage для персистентности.
